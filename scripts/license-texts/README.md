Standard license texts for registry archives that declare an SPDX license but
omit its standalone text. Apache-2.0 was copied from the locked local arrayvec
0.7.8 distribution; CC0-1.0 from wayland-protocols-plasma 0.3.12. These are
license texts, not new renderer dependencies. The collector keeps each affected
upstream archive in full so copyright/attribution notices in source and XML are
not lost. The per-package manifest records the upstream declaration.
